Let's go fishing

This is a scholar project. The goal was to implement the foundations for connected virtual aquariums. The idea is that there is an aquarium, handled by the TCP/IP server, and clients can connect to the server to get views on parts of the aquarium. When using several computers, one can put the monitors side by side and observe the fishes swim from one screen to the other ! The project is implemented using C/C++.
